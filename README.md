# Teo 1-99

一齊食，一齊畀分，一齊傾偈。Designed by Teo.

## Play
https://sharon-hiulam.github.io/teo-1-99/

Choose 2–4 players, enter names and three foods. Pass one phone around to secretly score each food from 1 to 99. Reveal the scores together, chat for 30 seconds, then continue. The final table shows each vote, the average and gold/silver/bronze medals. Ties share a rank (competition ranking).

The game runs entirely in your browser. Names and scores are not uploaded. Reloading starts a new game.

## Files
- `index.html`: self-contained production game, no external assets required.
- `source.zip`: editable React/TypeScript source and dependency lockfile. Extract, install with pnpm, then run `pnpm build` to produce `dist-github`.

Built with React, Base UI, Vite and Tailwind CSS.
